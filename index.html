Фронтенд в 2025

Путь для русскоязычных: бесплатные ресурсы, востребованные технологии, реальные собеседования в РФ.

1. Основы: HTML и CSS

→ Гайд: создай первую страницу за 1 час

→ Практика: HTML5Book — интерактивные упражнения

→ Видео: Полный курс от freeCodeCamp (с субтитрами)

2. JavaScript: от основ к DOM

→ Как сделать кнопку, которая что-то делает

→ Курс: learn.javascript.ru — лучший русскоязычный ресурс

→ Практика: Задачи на freeCodeCamp

3. Фреймворки: React или Vue?

→ В РФ чаще требуют React (Сбер, Тинькофф, VK, Ozon).

→ Начни с: Официальный туториал на русском

→ Альтернатива: Vue 3 (проще для новичков)

4. Инструменты: Git, npm, сборка

→ Как установить Git и делать коммиты

→ npm для начинающих (HTML5Book)

→ Совет: не бойся терминала — в 2025 году он обязателен.

5. Как устроиться на работу?

→ Собеседования в РФ: React + TypeScript + Git.

→ Портфолио: сделай 3 проекта (лендинг, todo-list, погода).

→ Где искать: hh.ru, Russian IT Community.
