1. Подготовка среды

1.1 Понимание экосистемы Java
  • Что такое JVM, JRE, JDK — в чём разница?
  • Почему Java кроссплатформенна?
  • Что такое LTS-версии (17, 21)? Какую выбрать в 2025?
1.2 Установка JDK
  • Где скачать: Eclipse Temurin (Adoptium) — официально, бесплатно, без вирусов.
  • Пошаговая установка
    • Windows: .msi → PATH автоматически
    • Mac: .pkg или через Homebrew
    • Linux: через пакетный менеджер (apt, yum)
  • Проверка: java -version, javac -version
1.3 Настройка IDE
  • IntelliJ IDEA Community (рекомендуется)
    • Скачать, установить, создать первый проект
    • Настройка кодировки (UTF-8)
  • Альтернатива: VS Code + Extension Pack for Java
  • Почему не Eclipse для новичков?
1.4 Первый запуск
  • Создать Hello.java
  • Скомпилировать: javac Hello.java
  • Запустить: java Hello

1.5 Основы работы с терминалом и ОС
  • Базовые команды (`cd`, `ls`, `mkdir`, `cat`)
