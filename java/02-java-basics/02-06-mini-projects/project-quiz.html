Консольная викторина

Главная → Java для карьеры → Консольная викторина

Консольная викторина — отличный способ применить всё, что вы уже знаете: переменные, условия, циклы и работу с пользовательским вводом. Программа будет задавать вопросы, принимать ответы и в конце показывать результат.

Что будет делать наша викторина?

  • Задавать 3 вопроса с выбором одного варианта (A, B, C)
  • Считать правильные ответы
  • Выводить итоговый счёт и поздравление
Quiz.java 
import java.util.Scanner;

public class Quiz {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        int score = 0;

        System.out.println("🌟 Добро пожаловать в викторину!");
        System.out.println("Выберите один вариант ответа (A, B или C).\n");

        // Вопрос 1
        System.out.println("1. Какой оператор используется для сравнения значений?");
        System.out.println("A) =\nB) ==\nC) ===");
        String answer1 = scanner.nextLine().trim().toUpperCase();
        if (answer1.equals("B")) {
            score++;
            System.out.println("✅ Верно!\n");
        } else {
            System.out.println("❌ Неверно. Правильный ответ: B\n");
        }

        // Вопрос 2
        System.out.println("2. Какой тип данных хранит true/false?");
        System.out.println("A) int\nB) String\nC) boolean");
        String answer2 = scanner.nextLine().trim().toUpperCase();
        if (answer2.equals("C")) {
            score++;
            System.out.println("✅ Верно!\n");
        } else {
            System.out.println("❌ Неверно. Правильный ответ: C\n");
        }

        // Вопрос 3
        System.out.println("3. Какой метод является точкой входа в программу?");
        System.out.println("A) start()\nB) main()\nC) run()");
        String answer3 = scanner.nextLine().trim().toUpperCase();
        if (answer3.equals("B")) {
            score++;
            System.out.println("✅ Верно!\n");
        } else {
            System.out.println("❌ Неверно. Правильный ответ: B\n");
        }

        // Итог
        System.out.println("🎉 Ваш результат: " + score + " из 3");
        if (score == 3) {
            System.out.println("Отлично! Вы — Java-гуру!");
        } else if (score >= 2) {
            System.out.println("Хорошо! Почти идеально.");
        } else {
            System.out.println("Повторите основы — у вас всё получится!");
        }

        scanner.close();
    }
}

Важно:

  • Используем .trim().toUpperCase(), чтобы игнорировать пробелы и регистр («b» и «B» — одинаково).
  • Сравниваем строки через .equals(), а не == — это частая ошибка новичков!
  • Не забывайте закрывать Scanner в конце.

Аналогия: Викторина — как экзамен в автошколе: вы отвечаете на вопросы, а система сразу говорит, правильно ли вы помните правила.

Как запустить?

  1. Сохраните код в файл Quiz.java
  2. В терминале: javac Quiz.java
  3. Затем: java Quiz

Идеи для улучшения

  • Добавьте больше вопросов из массива или списка.
  • Сделайте рандомный порядок вопросов.
  • Разрешите вводить «a», «б» или даже «1» — сделайте парсер ответов.
  • Сохраняйте рекорды в файл (позже, на уровне коллекций).
