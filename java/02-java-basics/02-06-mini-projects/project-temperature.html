Конвертер температуры

Главная → Java для карьеры → Конвертер температуры

Конвертер температуры — отличный мини-проект для закрепления основ Java: работы с числами, условиями и пользовательским вводом. Программа будет переводить градусы между шкалами Цельсия и Фаренгейта — как в реальных приложениях погоды.

Формулы конвертации

  • Цельсий → Фаренгейт: F = C × 9/5 + 32
  • Фаренгейт → Цельсий: C = (F − 32) × 5/9

Полный код программы

TemperatureConverter.java 
import java.util.Scanner;

public class TemperatureConverter {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.println("Выберите направление конвертации:");
        System.out.println("1. Цельсий → Фаренгейт");
        System.out.println("2. Фаренгейт → Цельсий");
        System.out.print("Ваш выбор (1 или 2): ");
        int choice = scanner.nextInt();

        System.out.print("Введите температуру: ");
        double temp = scanner.nextDouble();

        double result;
        if (choice == 1) {
            result = celsiusToFahrenheit(temp);
            System.out.printf("%.1f°C = %.1f°F%n", temp, result);
        } else if (choice == 2) {
            result = fahrenheitToCelsius(temp);
            System.out.printf("%.1f°F = %.1f°C%n", temp, result);
        } else {
            System.out.println("Ошибка: выберите 1 или 2.");
        }

        scanner.close();
    }

    // Метод: Цельсий → Фаренгейт
    public static double celsiusToFahrenheit(double celsius) {
        return celsius * 9.0 / 5.0 + 32;
    }

    // Метод: Фаренгейт → Цельсий
    public static double fahrenheitToCelsius(double fahrenheit) {
        return (fahrenheit - 32) * 5.0 / 9.0;
    }
}

Важно:

  • Используем 9.0 / 5.0, а не 9 / 5, чтобы избежать целочисленного деления.
  • Методы вынесены отдельно — это делает код чище и повторно используемым.
  • printf с %.1f округляет результат до одного знака после запятой.

Аналогия: Конвертер температуры — как переводчик между двумя языками: один говорит «20 градусов», другой слышит «68 градусов». Смысл тот же, а единицы — разные.

Как запустить?

  1. Сохраните код в файл TemperatureConverter.java
  2. В терминале: javac TemperatureConverter.java
  3. Затем: java TemperatureConverter

Идеи для улучшения

  • Добавьте поддержку Кельвинов.
  • Реализуйте цикл — чтобы можно было конвертировать много раз без перезапуска.
  • Сделайте проверку ввода: если пользователь ввёл букву вместо числа — обработайте ошибку.
