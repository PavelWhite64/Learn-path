Java для карьеры

Примитивы (int, double, boolean, char)

Главная → Java для карьеры → Примитивы (int, double, boolean, char)

В Java существует восемь примитивных типов данных — это базовые строительные блоки для хранения информации. Они называются «примитивными», потому что не являются объектами и работают напрямую с памятью. Четыре из них используются чаще всего — именно их мы и разберём.

1. int — целые числа

Используется для хранения целых чисел (без дробной части).

int age = 25;
int temperature = -10;
int population = 1400000000;

Диапазон: от -2 147 483 648 до +2 147 483 647. Этого хватает для большинства задач.

2. double — дробные числа

Используется для чисел с плавающей запятой (дробных).

double price = 199.99;
double pi = 3.14159;
double weight = 75.5;

Точность — около 15–16 десятичных знаков. В 99% случаев этого достаточно.

3. boolean — логическое значение

Может принимать только два значения: true (истина) или false (ложь).

boolean isStudent = true;
boolean hasLicense = false;
boolean isOnline = true;

Используется в условиях, циклах и проверках.

4. char — один символ

Хранит ровно один символ в одинарных кавычках.

char grade = 'A';
char symbol = '@';
char digit = '7';

Поддерживает буквы, цифры, знаки препинания и даже эмодзи (через Unicode): '😊'.

Важно: Примитивы пишутся строчными буквами (int, не Int). Если вы видите Integer, Double — это уже обёртки (ссылочные типы), а не примитивы.

Аналогия: Примитивы — как базовые ингредиенты на кухне: соль (int), вода (double), да/нет (boolean), одна специя (char). Из них можно приготовить любое блюдо — но сами по себе они просты и неделимы.

Практика: объявите переменные

public class DataTypesDemo {
    public static void main(String[] args) {
        int year = 2025;
        double gpa = 4.5;
        boolean isLearningJava = true;
        char firstLetter = 'J';

        System.out.println("Год: " + year);
        System.out.println("Средний балл: " + gpa);
        System.out.println("Учит Java? " + isLearningJava);
        System.out.println("Первая буква: " + firstLetter);
    }
}
