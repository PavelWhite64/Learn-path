Константы (final)

Главная → Java для карьеры → Константы (final)

В Java есть способ создать переменную, значение которой нельзя изменить после присваивания. Такие переменные называются константами, и объявляются они с помощью ключевого слова final.

Как объявить константу?

Просто добавьте final перед типом переменной:

final double PI = 3.14159;
final int MAX_USERS = 100;
final String APP_NAME = "BridgeLearn";

Попытка изменить такую переменную вызовет ошибку компиляции:

PI = 3.14; // Ошибка! Cannot assign a value to final variable 'PI'

Зачем нужны константы?

  • ✅ Безопасность — вы не случайно перезапишете важное значение.
  • ✅ Читаемость — имя вроде MAX_LOGIN_ATTEMPTS понятнее, чем просто 3.
  • ✅ Поддержка — если нужно изменить значение (например, увеличить лимит), править нужно в одном месте.

Соглашение об именовании

По общепринятому стилю (Google Java Style, Oracle), константы пишутся заглавными буквами с подчёркиваниями:

final int SECONDS_PER_HOUR = 3600;
final String DEFAULT_ENCODING = "UTF-8";

Это сразу сигнализирует другим разработчикам: «это значение не меняется».

Важно: final делает неизменяемой ссылку, а не объект. Например, если у вас final List names = new ArrayList<>();, вы не сможете присвоить names = другойСписок, но сможете изменять содержимое списка: names.add("Анна").

Аналогия: Обычная переменная — как стикер на банке: можно стереть надпись и написать новую. Константа (final) — как табличка, прикрученная болтами: надпись нельзя изменить без инструментов (а в Java — вообще нельзя).

Практика: используйте константы в программе

public class ConstantsDemo {
    public static void main(String[] args) {
        final double RATE = 0.15;
        final int HOURS_PER_DAY = 24;

        double tax = 1000 * RATE;
        int secondsInDay = HOURS_PER_DAY * 60 * 60;

        System.out.println("Налог: " + tax);
        System.out.println("Секунд в сутках: " + secondsInDay);
    }
}
