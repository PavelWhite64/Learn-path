Java для карьеры

Ссылочные типы (String, обёртки)

Главная → Java для карьеры → Ссылочные типы (String, обёртки)

Кроме примитивных типов (int, boolean и др.), в Java существуют ссылочные типы. Они позволяют работать с более сложными данными — текстом, коллекциями, объектами и даже «упаковывать» примитивы в объекты. Два самых важных примера — это String и обёртки (wrapper classes).

1. String — текст в Java

String — это не примитив, а полноценный класс. Он используется для хранения текста и всегда записывается в двойных кавычках:

String name = "Алиса";
String message = "Привет, мир!";
String empty = "";

Особенности:

  • String неизменяем (immutable): при «изменении» создаётся новый объект.
  • Поддерживает методы: .length(), .toUpperCase(), .equals() и др.
  • Автоматически импортируется — писать import java.lang.String; не нужно.

2. Обёртки (Wrapper Classes)

Для каждого примитивного типа существует «обёртка» — класс, который превращает примитив в объект:

Примитив Обёртка
int Integer
double Double
boolean Boolean
char Character

Пример:

Integer age = 30;      // автоупаковка (autoboxing)
Double price = 199.99;
Boolean active = true;

Зачем они нужны?

  • Работа с коллекциями (например, ArrayList не принимает int, только Integer).
  • Использование методов: Integer.parseInt("123"), Double.isNaN(x).
  • Возможность иметь значение null (в отличие от примитивов).

Важно: Не путайте int и Integer! Это разные типы. Хотя Java автоматически преобразует их друг в друга (автоупаковка/распаковка), в производительности и поведении есть нюансы.

Аналогия: Примитив — как монета в руке. Обёртка — как та же монета, завёрнутая в подарочную коробку с этикеткой. Коробка позволяет класть монету в набор (коллекцию), но она тяжелее и занимает больше места.

Практика: сравните примитив и обёртку

public class WrapperDemo {
    public static void main(String[] args) {
        int a = 100;
        Integer b = 100;

        System.out.println(a == b); // true (благодаря автоупаковке)
        System.out.println(b.toString()); // "100"
        System.out.println(String.valueOf(a)); // "100"
    }
}
