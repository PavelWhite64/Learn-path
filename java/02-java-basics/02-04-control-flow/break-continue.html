Java для карьеры

break, continue

Главная → Java для карьеры → break, continue

Операторы break и continue позволяют гибко управлять выполнением циклов. Они помогают досрочно завершить итерацию или выйти из цикла в зависимости от условий.

1. break — выйти из цикла

Оператор break немедленно прекращает выполнение цикла и передаёт управление следующей за ним инструкции.

for (int i = 1; i <= 10; i++) {
    if (i == 5) {
        break; // выйти из цикла при i = 5
    }
    System.out.println(i);
}
// Вывод: 1 2 3 4

Часто используется для поиска элемента: как только нашли — нет смысла продолжать.

2. continue — пропустить итерацию

Оператор continue прерывает текущую итерацию и переходит к следующей (проверяя условие цикла).

for (int i = 1; i <= 5; i++) {
    if (i == 3) {
        continue; // пропустить вывод для i = 3
    }
    System.out.println(i);
}
// Вывод: 1 2 4 5

Полезен, когда нужно обработать все элементы, кроме некоторых.

Работа с вложенными циклами

По умолчанию break и continue влияют только на **самый внутренний** цикл. Чтобы выйти из внешнего цикла, используются метки (labels) (редко, но бывает нужно):

outer:
for (int i = 1; i <= 3; i++) {
    for (int j = 1; j <= 3; j++) {
        if (i == 2 && j == 2) {
            break outer; // выйти из обоих циклов
        }
        System.out.println(i + "," + j);
    }
}

Важно: Не злоупотребляйте break и continue — особенно в сложных циклах. Иногда лучше переписать логику с помощью флагов или вынести в метод, чтобы код оставался читаемым.

Аналогия: break — как экстренная остановка эскалатора: всё прекращается сразу. continue — как пропустить одну ступеньку: эскалатор идёт дальше, но вы на этой ступени не стоите.

Практика: пропустить чётные числа, остановиться на 9

for (int n = 1; n <= 15; n++) {
    if (n % 2 == 0) {
        continue; // пропустить чётные
    }
    if (n == 9) {
        break; // остановиться на 9
    }
    System.out.println(n);
}
// Вывод: 1 3 5 7
