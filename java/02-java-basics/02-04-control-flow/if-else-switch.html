Условия: if, else if, switch

Главная → Java для карьеры → Условия: if, else if, switch

Управляющие конструкции позволяют программе принимать решения. В зависимости от условия код может выполнять один блок или другой. В Java для этого используются if, else if и switch.

1. Конструкция if — простое условие

Выполняет блок кода, только если условие истинно (true):

int age = 20;
if (age >= 18) {
    System.out.println("Вы совершеннолетний.");
}

2. if + else — два варианта

Если условие ложно — выполняется альтернативный блок:

if (age >= 18) {
    System.out.println("Доступ разрешён.");
} else {
    System.out.println("Доступ запрещён.");
}

3. else if — несколько условий

Позволяет проверить несколько вариантов подряд:

int score = 85;

if (score >= 90) {
    System.out.println("Отлично!");
} else if (score >= 70) {
    System.out.println("Хорошо.");
} else if (score >= 50) {
    System.out.println("Удовлетворительно.");
} else {
    System.out.println("Не сдал.");
}

Проверка идёт сверху вниз — выполняется только первый подходящий блок.

4. Конструкция switch — выбор по значению

Используется, когда нужно сравнить переменную с несколькими конкретными значениями:

int day = 3;
switch (day) {
    case 1:
        System.out.println("Понедельник");
        break;
    case 2:
        System.out.println("Вторник");
        break;
    case 3:
        System.out.println("Среда");
        break;
    default:
        System.out.println("Неизвестный день");
}

Современный Java (14+) поддерживает более краткий синтаксис без break:

switch (day) {
    case 1 -> System.out.println("Понедельник");
    case 2 -> System.out.println("Вторник");
    case 3 -> System.out.println("Среда");
    default -> System.out.println("Неизвестный день");
}

Важно:

  • В if условие всегда в круглых скобках.
  • Блок кода — в фигурных скобках (даже если одна строка — лучше не опускать).
  • В switch тип переменной может быть int, String, enum и некоторые другие.

Аналогия: if — как развилка на дороге: «если дождь — взять зонт». switch — как меню в ресторане: вы выбираете одно из готовых блюд.

Практика: определите сезон по месяцу

int month = 7;

if (month >= 3 && month <= 5) {
    System.out.println("Весна");
} else if (month >= 6 && month <= 8) {
    System.out.println("Лето");
} else if (month >= 9 && month <= 11) {
    System.out.println("Осень");
} else {
    System.out.println("Зима");
}
