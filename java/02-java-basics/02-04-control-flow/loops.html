Циклы: for, while, do-while

Главная → Java для карьеры → Циклы: for, while, do-while

Циклы позволяют выполнять один и тот же блок кода несколько раз — пока не будет выполнено определённое условие или не пройдены все элементы. В Java есть три основных вида циклов: for, while и do-while.

1. Цикл for — когда известно количество повторов

Используется, если вы заранее знаете, сколько раз нужно выполнить действие (например, 10 раз или для каждого элемента массива).

for (int i = 0; i < 5; i++) {
    System.out.println("Итерация: " + i);
}

Структура:

  • int i = 0 — инициализация (выполняется один раз)
  • i < 5 — условие продолжения
  • i++ — изменение счётчика после каждой итерации

2. Цикл while — пока условие истинно

Выполняется, пока условие остаётся true. Количество итераций может быть неизвестно заранее.

int count = 3;
while (count > 0) {
    System.out.println("Осталось: " + count);
    count--;
}

Важно: не забудьте изменять переменную внутри цикла — иначе получите бесконечный цикл!

3. Цикл do-while — выполнить хотя бы один раз

Отличается от while тем, что тело цикла выполняется **минимум один раз**, даже если условие изначально ложно.

int attempts = 0;
do {
    System.out.println("Попытка №" + (attempts + 1));
    attempts++;
} while (attempts < 3);

Полезен, например, для ввода данных: сначала запросить, потом проверить.

Важно:

  • Все три цикла взаимозаменяемы — выбор зависит от читаемости.
  • Бесконечный цикл можно прервать с помощью break.
  • Команда continue пропускает остаток текущей итерации и переходит к следующей.

Аналогия: for — как пройти все 10 этажей дома по одному. while — как ждать автобус: «пока не приедет — стоять». do-while — как позвонить другу: «позвонить хотя бы раз, даже если он не отвечает».

Практика: таблица умножения

for (int i = 1; i <= 5; i++) {
    for (int j = 1; j <= 5; j++) {
        System.out.print(i * j + "\t");
    }
    System.out.println();
}
