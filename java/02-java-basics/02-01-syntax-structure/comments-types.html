Виды комментариев

Главная → Java для карьеры → Виды комментариев

Комментарии — это пояснения в коде, которые игнорируются компилятором. Они нужны, чтобы вы или другие разработчики могли быстро понять, что делает тот или иной участок программы. В Java существует три вида комментариев.

1. Однострочный комментарий — //

Всё, что идёт после // до конца строки, считается комментарием.

// Это однострочный комментарий
int age = 25; // Возраст пользователя

Самый часто используемый тип — идеален для кратких пояснений.

2. Многострочный комментарий — /* ... */

Всё между /* и */ игнорируется, даже если занимает несколько строк.

/*
 * Этот блок кода временно отключён.
 * Он будет переписан в следующей версии.
 */
// calculateOldTax();

Часто используется для отключения целых участков кода или написания длинных пояснений.

3. Документирующий комментарий — /** ... */

Особый вид комментария, который используется для генерации документации (например, через инструмент javadoc). 

/**
 * Выводит приветствие в консоль.
 * @param name имя пользователя
 */
public static void greet(String name) {
    System.out.println("Привет, " + name + "!");
}

Такие комментарии поддерживают специальные теги: @param, @return, @throws и др.

Важно: Комментарии — не замена хорошему коду. Лучше писать понятные имена переменных и методов, чем заваливать код пояснениями. Но когда логика сложная — комментарий спасает часы отладки.

Аналогия: Комментарии — как заметки на полях учебника. Они не входят в текст лекции, но помогают понять, что именно преподаватель имел в виду.

/**
 * Простая программа-приветствие.
 * Точка входа в приложение.
 */
public class Hello {
    // Главный метод — запускается при старте программы
    public static void main(String[] args) {
        System.out.println("Привет, BridgeLearn!"); // Вывод в консоль
    }
}
