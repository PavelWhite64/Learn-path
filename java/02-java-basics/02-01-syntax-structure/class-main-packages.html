Java для карьеры

Класс, метод main, пакеты, импорты

Главная → Java для карьеры → Класс, метод main, пакеты, импорты

Любая Java-программа строится по строгим правилам. Даже самая простая программа «Привет, мир!» должна содержать класс и метод main. Кроме того, в реальных проектах используются пакеты и импорты. Давайте разберём каждую часть.

1. Класс — основа всего

В Java всё — объект, а объекты создаются на основе классов. Даже если вы пишете простой скрипт, он должен быть внутри класса.

public class Hello {
    // тело класса
}

Правила:

  • Имя класса должно совпадать с именем файла (Hello.java → класс Hello).
  • Класс объявляется с ключевым словом class.
  • Модификатор public означает, что класс доступен из других частей программы.

2. Метод main — точка входа

Это метод, с которого начинается выполнение программы. Без него JVM не знает, с чего начать.

public static void main(String[] args) {
    System.out.println("Привет, мир!");
}

Разберём по словам:

  • public — метод виден извне.
  • static — метод принадлежит классу, а не объекту (чтобы его можно было вызвать без создания экземпляра).
  • void — метод ничего не возвращает.
  • main — имя метода (обязательное).
  • String[] args — массив аргументов командной строки (можно оставить, даже если не используете).

3. Пакеты — как папки для классов

Пакеты группируют связанные классы и предотвращают конфликты имён.

package com.mycompany.app;

Эта строка должна быть первой в файле (до import и class). В файловой системе пакет соответствует структуре папок:

com/mycompany/app/Hello.java

4. Импорты — подключение других классов

Чтобы использовать класс из другого пакета (например, ArrayList или Scanner), его нужно импортировать:

import java.util.Scanner;
import java.util.ArrayList;

Некоторые классы (из пакета java.lang, например String, System) импортировать не нужно — они доступны по умолчанию.

Важно: Порядок в файле строгий:
1. package (если есть)
2. import (если есть)
3. Объявление class
Нарушение порядка вызовет ошибку компиляции.

Аналогия: Класс — как дом. Метод main — входная дверь. Пакет — адрес дома (город/улица/дом). Импорты — телефонная книга: чтобы позвонить соседу, нужно знать его номер (имя класса).

Полный пример программы

package hello;

import java.time.LocalDateTime;

public class Hello {
    public static void main(String[] args) {
        System.out.println("Привет!");
        System.out.println("Сейчас: " + LocalDateTime.now());
    }
}
