Java для карьеры

Объявление, параметры, возврат

Главная → Java для карьеры → Объявление, параметры, возврат

Методы — это именованные блоки кода, которые можно вызывать многократно. Они позволяют избежать дублирования, упрощают чтение и делают программу модульной. В этой статье вы узнаете, как объявлять методы, передавать в них данные и получать результат.

1. Объявление метода

Общий синтаксис:

модификатор тип_возврата имяМетода(параметры) {
    // тело метода
}

Пример простого метода без параметров и без возврата:

public static void sayHello() {
    System.out.println("Привет!");
}

Чтобы вызвать его, достаточно написать:

sayHello(); // Выведет: Привет!

2. Параметры — передача данных в метод

Параметры позволяют передавать значения в метод при вызове:

public static void greet(String name) {
    System.out.println("Привет, " + name + "!");
}

// Вызов:
greet("Анна"); // Привет, Анна!

Можно указать несколько параметров через запятую:

public static void printSum(int a, int b) {
    System.out.println(a + b);
}

3. Возврат значения — ключевое слово return

Если метод должен вернуть результат, укажите его тип вместо void и используйте return: 

public static int square(int x) {
    return x * x;
}

// Вызов:
int result = square(5); // result = 25

Тип возвращаемого значения должен совпадать с тем, что указан в объявлении.

Важно:

  • void означает «ничего не возвращать».
  • Метод может иметь много параметров, но возвращать — только одно значение.
  • После return выполнение метода немедленно завершается.

Аналогия: Метод — как кофемашина. → Параметры — это кнопки: «эспрессо», «латте». → Возврат — это чашка кофе на выходе. → Если метод void — машина просто мигнёт лампочкой (ничего не выдаёт).

Практика: метод для расчёта скидки

public static double applyDiscount(double price, double percent) {
    return price - (price * percent / 100);
}

// Использование:
double finalPrice = applyDiscount(1000, 15); // 850.0
