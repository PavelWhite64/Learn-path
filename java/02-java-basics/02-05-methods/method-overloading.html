Перегрузка методов

Главная → Java для карьеры → Перегрузка методов

В Java можно создать несколько методов с одинаковым именем, но разными параметрами. Это называется перегрузкой методов (method overloading). Компилятор сам определит, какой метод вызвать, по количеству и типу аргументов.

Зачем это нужно?

Перегрузка делает API удобнее: вы можете вызывать один и тот же метод с разными данными, не запоминая разные имена.

Пример из стандартной библиотеки:

System.out.println("Привет");   // принимает String
System.out.println(42);           // принимает int
System.out.println(true);         // принимает boolean

Это — один и тот же метод println, но перегруженный под разные типы.

Как перегрузить метод?

Методы считаются разными, если отличаются:

  • Количеством параметров
  • Типами параметров
  • Порядком параметров (если типы разные)

Возвращаемый тип не учитывается при перегрузке!

Пример: перегрузка метода приветствия

public static void greet() {
    System.out.println("Привет!");
}

public static void greet(String name) {
    System.out.println("Привет, " + name + "!");
}

public static void greet(String name, int age) {
    System.out.println("Привет, " + name + "! Вам " + age + " лет.");
}

Вызовы:

greet();                // Привет!
greet("Анна");          // Привет, Анна!
greet("Иван", 25);      // Привет, Иван! Вам 25 лет.

Важно:

  • Перегрузка — это компиляторный механизм: выбор метода происходит на этапе компиляции.
  • Нельзя перегрузить метод только по возвращаемому типу — будет ошибка.
  • Имена параметров не влияют на перегрузку.

Аналогия: Перегрузка — как функция «напечатать документ» в принтере: → можно отправить PDF, → можно — текстовый файл, → можно — фото. Имя действия одно, но обработка зависит от типа входных данных.

Практика: перегрузите метод вычисления площади

public static double area(double radius) {
    return Math.PI * radius * radius; // круг
}

public static double area(double a, double b) {
    return a * b; // прямоугольник
}

// Использование:
System.out.println(area(5));      // площадь круга
System.out.println(area(4, 6));   // площадь прямоугольника
