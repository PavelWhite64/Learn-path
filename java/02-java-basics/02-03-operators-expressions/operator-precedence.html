Приоритет операций

Главная → Java для карьеры → Приоритет операций

Когда в одном выражении участвует несколько операторов, Java должна решить, в каком порядке их выполнять. За это отвечает приоритет операций — набор правил, похожий на математический порядок действий.

Пример без скобок

int result = 10 + 5 * 2;

Что будет: (10 + 5) * 2 = 30 или 10 + (5 * 2) = 20?

Правильный ответ — 20, потому что оператор * имеет более высокий приоритет, чем +.

Основные правила приоритета (от высшего к низшему)

  1. Скобки () — всегда выполняются первыми.
  2. Унарные операторы: !, -x, ++, --
  3. Арифметические: *, /, % → потом +, -
  4. Сравнения: <, >, <=, >=
  5. Равенство: ==, !=
  6. Логические И / ИЛИ: && → потом ||
  7. Присваивание: =, +=, -= и др.

Ассоциативность

Если операторы имеют одинаковый приоритет, Java выполняет их слева направо (кроме унарных и присваивания):

int a = 10 - 4 - 2; // (10 - 4) - 2 = 4, а не 10 - (4 - 2) = 8

А вот присваивание — справа налево:

int x, y, z;
x = y = z = 5; // сначала z = 5, потом y = z, потом x = y

Важно: Не полагайтесь на память о приоритете. Если выражение неочевидно — ставьте скобки. Это делает код понятнее и предотвращает ошибки.

Аналогия: Приоритет операций — как правила дорожного движения. Без них все ехали бы как хотят, и постоянно происходили аварии. Скобки — как дорожный знак «уступить»: вы сами указываете, что важно.

Практика: разберите выражение

boolean flag = 5 > 3 && 2 + 2 == 4 || !true;

Порядок вычисления:

  1. 5 > 3 → true
  2. 2 + 2 → 4, затем 4 == 4 → true
  3. !true → false
  4. true && true → true
  5. true || false → true

Итог: flag = true.
