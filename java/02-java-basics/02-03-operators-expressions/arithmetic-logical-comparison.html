Арифметические, логические, сравнения

Главная → Java для карьеры → Арифметические, логические, сравнения

Операторы — это символы, которые выполняют операции над данными. В Java они делятся на несколько групп. Три самые важные для новичков — это арифметические, операторы сравнения и логические операторы. Они лежат в основе всех вычислений и условий.

1. Арифметические операторы

Используются для математических вычислений с числами:

Оператор Название Пример Результат
+ Сложение 5 + 3 8
- Вычитание 10 - 4 6
* Умножение 7 * 6 42
/ Деление 15 / 3 5
% Остаток от деления 10 % 3 1

Важно: при делении целых чисел результат тоже целый: 7 / 2 == 3.

2. Операторы сравнения

Сравнивают два значения и возвращают boolean (true или false):

Оператор Значение Пример Результат
== Равно 5 == 5 true
!= Не равно 5 != 3 true
> Больше 10 > 5 true
< Меньше 2 < 1 false
>= Больше или равно 5 >= 5 true
<= Меньше или равно 4 <= 3 false

3. Логические операторы

Работают с логическими значениями (boolean) и позволяют строить сложные условия:

Оператор Название Пример Результат
&& И (AND) true && false false
|| ИЛИ (OR) true || false true
! НЕ (NOT) !true false

Пример в коде:

int age = 20;
boolean hasLicense = true;
boolean canDrive = (age >= 18) && hasLicense; // true

Важно: Не путайте = (присваивание) и == (сравнение)! int x = 5; — присвоить значение. if (x == 5) — проверить равенство.

Аналогия: Арифметические операторы — как калькулятор. Операторы сравнения — как весы («тяжелее/легче»). Логические операторы — как выключатели: «включить свет, если день И дверь открыта».

Практика: проверка возраста и доступа

public class OperatorsDemo {
    public static void main(String[] args) {
        int userAge = 17;
        boolean isVerified = true;

        boolean isAdult = userAge >= 18;
        boolean hasAccess = isAdult || isVerified;

        System.out.println("Совершеннолетний? " + isAdult);
        System.out.println("Доступ разрешён? " + hasAccess);
    }
}
