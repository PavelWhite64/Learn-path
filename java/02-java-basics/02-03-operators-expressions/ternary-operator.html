Тернарный оператор

Главная → Java для карьеры → Тернарный оператор

Тернарный оператор — это краткая форма записи условия if-else в одну строку. Он удобен, когда нужно присвоить значение переменной в зависимости от условия.

Синтаксис

условие ? значение_если_true : значение_если_false

Пример:

int age = 20;
String status = (age >= 18) ? "Совершеннолетний" : "Несовершеннолетний";

Если age >= 18 — status станет "Совершеннолетний", иначе — "Несовершеннолетний".

Когда использовать?

Тернарный оператор уместен, когда:

  • Условие простое и легко читается.
  • Обе ветки возвращают значение одного типа.
  • Вы присваиваете результат переменной или используете его в выражении.

Не используйте тернарный оператор для сложной логики — это ухудшит читаемость.

Примеры

// Минимум из двух чисел
int a = 10, b = 15;
int min = (a < b) ? a : b;

// Приветствие в зависимости от времени суток
boolean isMorning = true;
String greeting = isMorning ? "Доброе утро!" : "Здравствуйте!";

// Вывод в консоль
System.out.println( score >= 60 ? "Сдал" : "Не сдал" );

Важно: Тернарный оператор — это выражение, а не инструкция. Он всегда возвращает значение. Поэтому его нельзя использовать вместо if, если вы не присваиваете результат.

Аналогия: Тернарный оператор — как выбор кофе: «Если есть молоко — латте, иначе — эспрессо». Всё решение умещается в одном предложении.
