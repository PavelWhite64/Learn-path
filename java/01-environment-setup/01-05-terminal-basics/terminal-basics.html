Java для карьеры

Базовые команды (cd, ls, mkdir, cat)

Главная → Java для карьеры → Базовые команды (cd, ls, mkdir, cat)

При работе с Java вам часто придётся использовать терминал (командную строку): чтобы компилировать код, запускать программы, управлять проектами. Даже если вы используете IDE, понимание базовых команд сэкономит вам часы времени. Ниже — четыре ключевые команды, которые нужно знать с самого начала.

1. pwd — где я?

Показывает текущую директорию (путь к папке, в которой вы находитесь).

$ pwd
/home/user/java-projects

2. ls — что здесь есть? (Linux/macOS)

Выводит список файлов и папок в текущей директории.

$ ls
Hello.java  README.md  src/

На Windows в PowerShell или CMD используйте: dir.

3. cd — перейти в другую папку

Команда cd (change directory) позволяет перемещаться по файловой системе.

  • cd имя_папки — войти в папку
  • cd .. — подняться на уровень выше
  • cd ~ — вернуться в домашнюю папку (Linux/macOS)
  • cd C:\projects — перейти по абсолютному пути (Windows)
$ cd hello
$ pwd
/home/user/java-projects/hello

4. mkdir — создать папку

Создаёт новую директорию.

$ mkdir my-java-app
$ ls
my-java-app/

5. cat — посмотреть содержимое файла (Linux/macOS)

Выводит текст файла прямо в терминал.

$ cat Hello.java
public class Hello {
    public static void main(String[] args) {
        System.out.println("Привет!");
    }
}

На Windows используйте: type Hello.java.

Важно: В терминале регистр важен! Hello.java ≠ hello.java. Также пробелы в именах файлов требуют экранирования (лучше их избегать).

Аналогия: Терминал — как GPS для файловой системы. pwd — «где я?», ls — «что вокруг?», cd — «ехать туда», mkdir — «построить новый дом», cat — «заглянуть внутрь».

Практика: создайте проект вручную

Попробуйте выполнить в терминале:

mkdir ~/java/hello
cd ~/java/hello
echo 'public class Hello { public static void main(String[] args) { System.out.println("Терминал работает!"); } }' > Hello.java
javac Hello.java
java Hello

Если вы видите сообщение — вы всё сделали правильно!
