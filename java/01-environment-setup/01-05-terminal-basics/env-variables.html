Java для карьеры

Переменные окружения

Главная → Java для карьеры → Переменные окружения (PATH, JAVA_HOME)

Когда вы устанавливаете JDK, система должна «знать», где его искать. За это отвечают переменные окружения — специальные настройки операционной системы. Две из них критически важны для Java: PATH и JAVA_HOME.

Что такое PATH?

PATH — это список папок, в которых система ищет исполняемые файлы (команды), когда вы что-то вводите в терминале.

Например, когда вы пишете java -version, ОС ищет файл java.exe (Windows) или java (macOS/Linux) в папках, перечисленных в PATH.

Если JDK установлен правильно (через .msi, .pkg или пакетный менеджер), он автоматически добавляет свои команды (java, javac) в PATH.

Что такое JAVA_HOME?

JAVA_HOME — это переменная, которая указывает на корневую папку установленного JDK (например, C:\Program Files\Eclipse Adoptium\jdk-17.0.12-hotspot).

Она не нужна для запуска простых программ, но требуется многим инструментам: — Maven, Gradle — IntelliJ IDEA, VS Code (иногда) — Spring Boot, Tomcat, Jenkins и другим серверам

Важно: При установке через официальный установщик (.msi / .pkg) переменная JAVA_HOME часто не настраивается автоматически. Её нужно задать вручную — особенно если вы планируете использовать сборщики или фреймворки.

Как проверить переменные?

Откройте терминал и выполните:

Для PATH:

# Показать, где находится команда java
which java      # macOS / Linux
where java      # Windows (CMD)
Get-Command java # Windows (PowerShell)

Для JAVA_HOME:

echo $JAVA_HOME   # macOS / Linux
echo %JAVA_HOME%  # Windows (CMD)
$env:JAVA_HOME    # Windows (PowerShell)

Если вывод пустой — переменная не задана.

Аналогия: PATH — как список адресов, по которым курьер ищет кафе с вашим заказом. JAVA_HOME — это точный адрес кухни этого кафе. Курьеру (терминалу) достаточно знать район (PATH), но менеджеру (Maven) нужен точный адрес (JAVA_HOME).

Нужно ли настраивать вручную?

Если вы:

  • Только учитесь и запускаете простые программы через javac / java — не нужно.
  • Планируете использовать Spring Boot, Maven, Gradle или CI/CD — рекомендуется задать JAVA_HOME.

Как настроить JAVA_HOME вручную — отдельная тема (см. документацию вашей ОС). Но для старта — достаточно, чтобы работали команды java и javac.
