Почему именно UTF-8?

UTF-8 — современный стандарт кодировки, который поддерживает все языки мира, включая русский, и используется по умолчанию в большинстве систем. Java 17+ и современные ОС (Windows 10/11, macOS, Linux) также используют UTF-8 как стандарт.

Как настроить UTF-8 в IntelliJ IDEA

Сделайте это один раз — и забудьте о проблемах с текстом навсегда:

  1. Откройте IntelliJ IDEA.
  2. Зайдите в настройки:
    • Windows/Linux: File → Settings
    • macOS: IntelliJ IDEA → Preferences
  3. В левом меню перейдите: Editor → File Encodings.
  4. Установите следующие значения:
    • Global Encoding: UTF-8
    • Project Encoding: UTF-8
    • Default encoding for properties files: UTF-8
  5. Поставьте галочку: ✓ Transparent native-to-ascii conversion (особенно важно для файлов .properties).
  6. Нажмите OK и перезапустите IDE (рекомендуется).

Важно: Эта настройка влияет только на новые проекты. Если у вас уже есть проект с «битым» текстом — откройте нужный файл, нажмите на текущую кодировку в правом нижнем углу (например, «Windows-1251») и выберите «Convert to UTF-8».

Аналогия: Кодировка — как язык перевода. Если вы говорите по-русски, а собеседник слушает через переводчик с английского, он услышит бессмыслицу. UTF-8 — это «универсальный переводчик», понятный всем.

Проверка: работает ли UTF-8?

Создайте новый класс и добавьте:

public class TestEncoding {
    public static void main(String[] args) {
        System.out.println("Привет, мир! 🌍");
    }
}

Запустите программу. Если в консоли отображается читаемый русский текст и эмодзи — всё настроено правильно!
