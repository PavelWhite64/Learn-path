Java для карьеры

Скомпилировать: javac Hello.java

Главная → Java для карьеры → Скомпилировать: javac Hello.java

Теперь, когда у вас есть файл Hello.java, его нужно превратить в формат, который понимает JVM. Этот процесс называется компиляцией, и выполняется с помощью команды javac (Java Compiler).

Шаг 1: Откройте терминал в папке с файлом

Перейдите в ту папку, где лежит Hello.java:

  • Windows: зажмите Shift + ПКМ в папке → «Открыть окно PowerShell здесь» или «Командная строка».
  • macOS/Linux: откройте Terminal и используйте команду cd, например: cd ~/java/hello.

Шаг 2: Выполните компиляцию

Введите команду:

javac Hello.java

Если всё сделано правильно — команда выполнится без ошибок и без сообщений.

Проверьте содержимое папки — появился новый файл:

Hello.class

Это и есть байт-код — промежуточный код, который может выполнить JVM.

Важно: Если вы видите ошибку вроде «javac: command not found», значит, JDK не установлен или не добавлен в PATH. Вернитесь к статье «Проверка: java -version, javac -version».

Аналогия: Компиляция — как перевод с русского языка на международный технический жаргон. Вы написали рецепт на родном языке (.java), а повар-робот (JVM) понимает только стандартный формат (.class). javac — это переводчик.

Что внутри файла .class?

Это не текст, а бинарный файл. Открывать его в Блокноте бесполезно — он предназначен только для JVM. Но именно он позволяет запускать программу на любом устройстве, где установлена Java.
