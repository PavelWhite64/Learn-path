Типичные ошибки и как их исправить

Главная → Java для карьеры → Типичные ошибки и как их исправить

При первом запуске Java-программы новички часто сталкиваются с ошибками. Большинство из них легко исправить — главное понять, что пошло не так. Ниже — разбор самых частых проблем.

Ошибка 1: «'javac' is not recognized as an internal or external command»

Что значит: Система не знает команду javac.

Причина: JDK не установлен или не добавлен в переменную окружения PATH.

Как исправить:

  • Убедитесь, что вы установили именно JDK (например, Eclipse Temurin), а не JRE.
  • Если вы установили архив (.zip), лучше переустановите через .msi (Windows), .pkg (macOS) или пакетный менеджер (Linux).
  • После установки перезапустите терминал.
  • Проверьте командой: javac -version.

Ошибка 2: «Error: Could not find or load main class Hello»

Что значит: JVM не может найти класс Hello.

Причины и решения:

  • Вы запускаете команду не из той папки. Убедитесь, что файл Hello.class находится в текущей директории.
  • Вы написали java Hello.class — уберите расширение! Правильно: java Hello.
  • Имя класса в коде не совпадает с именем файла (регистр букв важен!).

Ошибка 3: «Class names are only accepted if annotation processing is explicitly requested»

Пример: вы ввели javac Hello вместо javac Hello.java.

Исправление: всегда указывайте полное имя файла с расширением .java при компиляции.

Причина: файл сохранён не в кодировке UTF-8 или терминал использует другую кодировку.

Как исправить:

  • Сохраняйте .java-файлы в кодировке **UTF-8** (в Блокноте: «Сохранить как → UTF-8»).
  • В IntelliJ IDEA или VS Code убедитесь, что стоит UTF-8 (см. статью «Настройка кодировки (UTF-8)»).
  • В Windows-терминале можно временно выполнить: chcp 65001 (включает UTF-8).

Важно: Большинство ошибок возникают из-за трёх причин: 1) JDK не установлен, 2) неправильное имя файла/класса, 3) запуск не из той папки. Проверяйте их в первую очередь!

Аналогия: Ошибки компиляции и запуска — как ошибки в рецепте: забыли указать ингредиент (нет main), написали «мука» вместо «сахар» (ошибка в коде), или пытаетесь печь торт на плите, а не в духовке (неправильная команда). Главное — читать внимательно.
