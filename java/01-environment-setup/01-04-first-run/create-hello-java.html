Java для карьеры

Создать Hello.java

Главная → Java для карьеры → Создать Hello.java

Первый шаг в любом языке программирования — написать программу «Привет, мир!». В Java это файл с именем Hello.java. Давайте создадим его вручную, без IDE, чтобы понять, как всё работает «под капотом».

Шаг 1: Создайте папку для проекта

Откройте проводник (или Finder на Mac) и создайте новую папку, например:

C:\java-projects\hello

или

~/java/hello

Это будет ваша рабочая директория.

Шаг 2: Создайте файл Hello.java

Откройте любой текстовый редактор (Блокнот, TextEdit, VS Code, Nano и т.д.) и введите следующий код:

public class Hello {
    public static void main(String[] args) {
        System.out.println("Привет, мир!");
    }
}

Важно: Имя класса (Hello) должно точно совпадать с именем файла (Hello.java), включая регистр. Иначе компилятор выдаст ошибку.

Шаг 3: Сохраните файл

Сохраните файл как Hello.java в созданную папку. Убедитесь, что:

  • Расширение — именно .java (не .txt!)
  • Кодировка — UTF-8 (в Блокноте: «Сохранить как» → «Кодировка: UTF-8»)

Аналогия: Файл Hello.java — это рецепт. А компилятор (javac) — повар, который превращает рецепт в готовое блюдо (байт-код). Без точного названия рецепта повар не поймёт, что готовить.

Что дальше?

→ Скомпилировать: javac Hello.java
→ Запустить: java Hello
→ Вернуться к дорожной карте
