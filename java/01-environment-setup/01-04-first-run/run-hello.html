Поздравляем! Вы уже создали файл Hello.java и скомпилировали его в Hello.class. Теперь остался последний шаг — запустить программу и увидеть результат в терминале.

Как запустить Java-программу

Убедитесь, что вы находитесь в той же папке, где лежит файл Hello.class. Затем выполните команду:

java Hello

Обратите внимание: вы указываете **имя класса** (Hello), а не имя файла и без расширения .class.

Что должно произойти?

Если всё сделано правильно, в терминале появится:

Привет, мир!

Это значит, что JVM успешно загрузила байт-код из Hello.class и выполнила метод main.

Важно: Если вы видите ошибку Error: Could not find or load main class Hello, проверьте:

  • Находитесь ли вы в правильной папке (где лежит Hello.class)
  • Правильно ли написано имя класса (регистр букв важен!)
  • Есть ли в классе метод public static void main(String[] args)

Аналогия: Компиляция (javac) — это как печать книги. Запуск (java) — это когда читатель берёт эту книгу и начинает читать. Без книги — не прочитаешь. Без читателя — книга просто лежит.

Почему именно так?

Команда java запускает **JVM**, которая ищет указанный класс, загружает его и ищет внутри метод main — точку входа в любую Java-программу. Именно с него начинается выполнение.
