Альтернатива: VS Code + Extension Pack for Java

Главная → Java для карьеры → Альтернатива: VS Code + Extension Pack for Java

IntelliJ IDEA — отличный выбор, но если вы уже используете Visual Studio Code (VS Code) или предпочитаете лёгкие редакторы, вы тоже можете писать на Java. Для этого достаточно установить официальный Extension Pack for Java от Microsoft и Red Hat.

Почему VS Code — хорошая альтернатива?

  • ✅ Бесплатный и с открытым исходным кодом.
  • ✅ Лёгкий и быстрый — запускается за секунды.
  • ✅ Поддерживает Java «из коробки» после установки пакета расширений.
  • ✅ Идеален, если вы планируете в будущем работать с JavaScript, Python, Go и другими языками.

Шаг 1: Установите VS Code

Если у вас ещё не установлен VS Code:

  1. Перейдите на официальный сайт: https://code.visualstudio.com/
  2. Скачайте установщик для вашей ОС (Windows, macOS, Linux).
  3. Установите программу, следуя инструкциям.

Шаг 2: Установите Extension Pack for Java

  1. Откройте VS Code.
  2. Нажмите на иконку расширений (четыре квадрата слева) или Ctrl+Shift+X (Cmd+Shift+X на Mac).
  3. В поиске введите: Extension Pack for Java.
  4. Найдите пакет от **Microsoft** (автор: Microsoft, Red Hat).
  5. Нажмите Install.

Этот пакет включает всё необходимое: Language Support, Debugger, Test Runner, Maven/Gradle поддержку и даже базовый Spring Boot-инструментарий.

Важно: Убедитесь, что у вас уже установлен JDK (например, Eclipse Temurin 17 или 21). VS Code не включает JDK — он только использует тот, что установлен в системе.

Шаг 3: Создайте первый проект

  1. Нажмите Ctrl+Shift+P (Cmd+Shift+P на Mac) и введите: Java: Create Java Project.
  2. Выберите No build tools (для простого старта).
  3. Укажите папку для проекта.
  4. VS Code создаст структуру с папкой src.
  5. Откройте src, создайте файл Hello.java и введите:
public class Hello {
    public static void main(String[] args) {
        System.out.println("Привет из VS Code!");
    }
}
  1. Нажмите зелёную стрелку ▶️ над методом main — программа запустится в терминале.

Аналогия: IntelliJ IDEA — как профессиональная фотостудия. VS Code с расширениями — как хороший смартфон с продвинутой камерой: не так мощно, но удобно, быстро и «всё в одном».

Когда выбирать VS Code?

VS Code подойдёт, если:

  • Вы учитесь и не хотите «тяжёлую» IDE.
  • Вы уже работаете с другими языками в VS Code.
  • Ваш компьютер слабый (менее 8 ГБ ОЗУ).

Для сложных проектов на Spring Boot, Hibernate или микросервисов в будущем вы, скорее всего, перейдёте на IntelliJ IDEA — но для старта VS Code более чем достаточно.
