Linux: через пакетный менеджер (apt, yum)

Главная → Java для карьеры → Linux: через пакетный менеджер (apt, yum)

На Linux JDK можно установить быстро и безопасно — с помощью встроенного пакетного менеджера. Выбор команды зависит от вашего дистрибутива: apt для Ubuntu/Debian, dnf или yum для Fedora/CentOS/RHEL.

Шаг 1: Определите ваш дистрибутив

Откройте терминал и выполните:

cat /etc/os-release

Если в строке ID= указано ubuntu или debian — используйте apt.
Если fedora, rhel или centos — используйте dnf (новые версии) или yum (старые).

Способ 1: Ubuntu / Debian (через apt)

Обновите список пакетов и установите Eclipse Temurin (рекомендуется):

sudo apt update
sudo apt install -y wget apt-transport-https gnupg
wget -O - https://packages.adoptium.net/artifactory/api/gpg/key/public | sudo gpg --dearmor -o /usr/share/keyrings/adoptium.gpg
echo "deb [signed-by=/usr/share/keyrings/adoptium.gpg] https://packages.adoptium.net/artifactory/deb $(awk -F= '/^VERSION_CODENAME/{print$2}' /etc/os-release) main" | sudo tee /etc/apt/sources.list.d/adoptium.list
sudo apt update
sudo apt install -y temurin-17-jdk  # или temurin-21-jdk

Способ 2: Fedora / RHEL / CentOS (через dnf или yum)

Для современных версий (Fedora 22+, RHEL 8+, CentOS Stream):

sudo dnf install -y https://packages.adoptium.net/artifactory/rpm/centos7/adoptium-rpm-release.el7.rpm
sudo dnf install -y temurin-17-jdk  # или temurin-21-jdk

Для старых систем с yum (например, CentOS 7):

sudo yum install -y wget
sudo rpm --import https://packages.adoptium.net/artifactory/api/gpg/key/public
sudo yum install -y https://packages.adoptium.net/artifactory/rpm/centos7/adoptium-rpm-release.el7.rpm
sudo yum install -y temurin-17-jdk

Важно: Устанавливайте именно -jdk (а не -jre), чтобы получить компилятор javac. Для разработки нужен JDK — как объяснялось в статье «Что такое JVM, JRE, JDK».

Аналогия: Пакетный менеджер — как официальный магазин приложений. Вы не скачиваете .exe с сайта, а ставите программу через проверенный канал, который сам обновляет зависимости и следит за безопасностью.

Проверка установки

После установки выполните в терминале:

java -version
javac -version

Если вы видите версию вроде Temurin-17.0.12 — всё готово! Вы можете писать и компилировать Java-код.
