Windows: .msi → PATH автоматически

Главная → Java для карьеры → Windows: .msi → PATH автоматически

Если вы скачали JDK для Windows в формате .msi (например, Eclipse Temurin), то при установке вам не нужно вручную настраивать переменную PATH. Установщик делает это за вас — автоматически и безопасно.

Почему .msi — лучший выбор для Windows

Формат .msi — это стандартный установочный пакет Windows. В отличие от архивов (.zip, .tar.gz), он:

  • ✅ Автоматически добавляет java и javac в системный PATH
  • ✅ Регистрирует JDK в списке установленных программ («Панель управления → Программы»)
  • ✅ Позволяет легко обновлять или удалять JDK через стандартные средства Windows

Важно: Убедитесь, что вы скачали именно файл с расширением .msi, а не .zip. Только .msi настраивает PATH автоматически.

Как проверить, что PATH настроен?

После установки:

  1. Закройте все открытые окна терминала (если были открыты до установки).
  2. Откройте новое окно командной строки: нажмите Win + R, введите cmd и нажмите Enter.
  3. Выполните команды:
java -version
javac -version

Если вы видите версию (например, Temurin-17.0.12), значит — всё работает! PATH настроен корректно.

Аналогия: Установка через .msi — как поставить принтер через «Добавить устройство»: Windows сама найдёт драйверы и настроит подключение. А архив — как вручную копировать файлы драйверов и править реестр. Зачем, если можно проще?

Что делать, если команды не работают?

Возможные причины:

  • Вы установили архив (.zip), а не .msi
  • Вы не перезапустили терминал после установки
  • Антивирус или корпоративная политика заблокировала изменение PATH

В этом случае: переустановите JDK, выбрав именно .msi-файл с сайта adoptium.net.
