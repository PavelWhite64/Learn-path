Java для карьеры

Проверка: java -version, javac -version

Главная → Java для карьеры → Проверка: java -version, javac -version

После установки JDK важно убедиться, что система «видит» команды java и javac. Это означает, что переменная окружения PATH настроена правильно — и вы готовы писать код.

Как проверить установку?

Откройте терминал (или командную строку) и выполните две команды:

1. Проверка запуска Java:

java -version

Эта команда показывает, какая версия JVM установлена и может ли система запускать Java-программы.

2. Проверка компилятора:

javac -version

Эта команда проверяет наличие компилятора Java. Без него вы не сможете превратить файл .java в исполняемый байт-код.

Важно: Обе команды должны работать без ошибок. Если вы видите «команда не найдена» — JDK либо не установлен, либо не добавлен в PATH. В этом случае вернитесь к инструкции по установке для вашей ОС.

Что считать успешным результатом?

Пример корректного вывода для Eclipse Temurin 17:

$ java -version
openjdk version "17.0.12" 2024-07-16 LTS
OpenJDK Runtime Environment Temurin-17.0.12+7 (build 17.0.12+7-LTS)
OpenJDK 64-Bit Server VM Temurin-17.0.12+7 (build 17.0.12+7-LTS, mixed mode)
$ javac -version
javac 17.0.12

Главное — чтобы в выводе фигурировало название дистрибутива (Temurin) и версия (17 или 21).

Аналогия: Команды java и javac — как проверка, есть ли бензин в машине и работает ли двигатель. Даже если вы только купили авто, сначала нужно убедиться, что оно заводится.

Что делать, если команды не работают?

  • Убедитесь, что вы установили именно JDK, а не JRE.
  • Если вы использовали архив (.zip, .tar.gz), возможно, PATH не настроен — лучше переустановить через .msi (Windows), .pkg или Homebrew (macOS), или пакетный менеджер (Linux).
  • Закройте и снова откройте терминал — изменения в PATH применяются только в новых сессиях.
