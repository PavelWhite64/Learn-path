Java для карьеры

Что такое JVM, JRE, JDK — в чём разница?

Главная → Java для карьеры → Что такое JDK?

Если вы только начинаете изучать Java, вас наверняка запутали эти три аббревиатуры. Давайте разберёмся просто и без жаргона — что есть что, и что именно нужно установить, чтобы писать программы на Java в 2025 году.

🔹 JVM — Java Virtual Machine

JVM — это «двигатель» Java. Именно она запускает ваш код.

Когда вы компилируете программу на Java, она превращается не в машинный код, а в байт-код (файл с расширением .class). JVM читает этот байт-код и выполняет его на любом устройстве — будь то Windows, Mac или сервер в облаке.

Благодаря JVM Java — кроссплатформенный язык: «написал один раз — запустил где угодно».

🔹 JRE — Java Runtime Environment

JRE — это «минимальный набор для запуска».

Он включает в себя:

  • JVM (чтобы запускать код),
  • Стандартные библиотеки Java (например, java.lang, java.util).

Если вы просто хотите запустить чужую Java-программу (например, Minecraft или корпоративное приложение), вам нужен только JRE.

Но если вы разработчик — JRE вам не хватит.

Аналогия: Представьте, что Java-программа — это фильм.
→ JVM — это проектор.
→ JRE — это проектор + экран + колонки.
→ А JDK — это ещё и камера, свет, сценарий — всё, чтобы снять фильм самому.

🔹 JDK — Java Development Kit

JDK — это полный комплект для разработчика. Именно его вы должны установить.

JDK включает в себя:

  • JRE (а значит, и JVM),
  • Компилятор javac (превращает .java в .class),
  • Инструменты отладки (jconsole, jvisualvm),
  • Документацию (JavaDocs).

Без JDK вы не сможете написать и скомпилировать ни одной Java-программы.

💡 Что устанавливать в 2025 году?

Только JDK. Современные дистрибутивы (например, Eclipse Temurin) поставляются как JDK — и включают всё необходимое.

Вам не нужно отдельно ставить JRE или JVM — они уже внутри JDK.

🔹 Где скачать JDK?

Рекомендуемый источник — Eclipse Temurin (бывш. AdoptOpenJDK):

  • Бесплатный и открытый,
  • Поддерживается сообществом Eclipse,
  • Доступен для Windows, Mac, Linux,
  • Используется в Сбере, Тинькофф и других компаниях РФ.

Выбирайте версию Java 17 или 21 (LTS) — они стабильны и будут поддерживаться годы.
