Mac: .pkg или через Homebrew

Главная → Java для карьеры → Mac: .pkg или через Homebrew

На macOS вы можете установить JDK двумя надёжными способами: через официальный .pkg-установщик или с помощью пакетного менеджера Homebrew. Оба варианта бесплатны, безопасны и подходят для обучения в 2025 году.

Способ 1: Установка через .pkg (официальный установщик)

Это самый простой путь для новичков:

  1. Перейдите на официальный сайт Eclipse Temurin.
  2. Выберите версию Java 17 или Java 21 (LTS).
  3. В разделе «Operating System» выберите macOS.
  4. Скачайте файл с расширением .pkg.
  5. Дважды кликните по файлу и следуйте инструкциям установщика.

После завершения JDK будет установлен в /Library/Java/JavaVirtualMachines/, а команды java и javac — доступны в терминале.

Способ 2: Установка через Homebrew

Если вы уже используете Homebrew (популярный пакетный менеджер для macOS), установка займёт одну команду:

  1. Убедитесь, что Homebrew установлен. Если нет — установите с brew.sh.
  2. Откройте Terminal и выполните:
brew install temurin

Эта команда установит последнюю LTS-версию Temurin (обычно Java 21). Если нужна Java 17 — используйте:

brew install temurin17

Homebrew автоматически добавит JDK в PATH, и вы сразу сможете использовать java и javac.

Важно: После установки любого способа закройте и снова откройте Terminal — иначе система может не увидеть новые команды.

Аналогия: Установка через .pkg — как поставить приложение из App Store: просто и наглядно. Установка через Homebrew — как использовать командную строку для опытных пользователей: быстро, точно и легко обновляется.

Как проверить, что всё работает?

В новом окне Terminal выполните:

java -version
javac -version

Если вы видите версию вроде Temurin-21.0.2 — поздравляем! JDK установлен успешно.
