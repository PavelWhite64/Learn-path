Скачать, установить, создать первый проект

Главная → Java для карьеры → Скачать, установить, создать первый проект

IntelliJ IDEA Community — бесплатная и мощная среда разработки от JetBrains, идеально подходящая для изучения Java. В этой статье вы скачаете её, установите и создадите свой первый проект за 5 минут.

Шаг 1: Скачайте IntelliJ IDEA Community

Перейдите на официальный сайт: https://www.jetbrains.com/idea/download/

На странице вы увидите две версии:

  • Community — бесплатная, с поддержкой Java, Kotlin, Scala и других JVM-языков.
  • Ultimate — платная, с поддержкой веба, баз данных и фреймворков (Spring и др.).

Для обучения Java в 2025 году вам нужна именно Community. Нажмите «Download» под ней.

Сайт автоматически определит вашу ОС (Windows, macOS или Linux) и предложит нужный установщик.

Шаг 2: Установите программу

Запустите скачанный файл:

  • Windows: запустите .exe и следуйте инструкциям (можно оставить все настройки по умолчанию).
  • macOS: перетащите значок IntelliJ IDEA в папку Applications.
  • Linux: распакуйте архив и запустите скрипт bin/idea.sh (или установите через Toolbox App или snap).

Установка займёт 1–3 минуты. После завершения запустите IntelliJ IDEA.

Важно: Убедитесь, что у вас уже установлен JDK (например, Eclipse Temurin 17 или 21). IntelliJ IDEA не включает JDK «из коробки» — она использует тот, что установлен в системе.

Шаг 3: Создайте первый проект

  1. При первом запуске нажмите «New Project».
  2. Убедитесь, что в поле Project SDK выбран ваш JDK (например, «17 Temurin»). Если нет — нажмите «Add JDK» и укажите путь к папке с JDK.
  3. Оставьте тип проекта как «Java».
  4. Нажмите «Next», затем «Finish».
  5. В левом окне (Project) кликните правой кнопкой по папке src → New → Java Class.
  6. Назовите класс Hello и нажмите OK.
  7. В открывшемся файле введите:
public class Hello {
    public static void main(String[] args) {
        System.out.println("Привет, BridgeLearn!");
    }
}
  1. Нажмите зелёную стрелку ▶️ слева от метода main — программа запустится, и вы увидите приветствие внизу в консоли.

Аналогия: Установка IntelliJ IDEA — как завести себе цифровой рабочий стол с лампой, блокнотом и принтером. Без него можно писать код в Блокноте, но зачем, если можно — с подсветкой, автодополнением и одной кнопкой запуска?
